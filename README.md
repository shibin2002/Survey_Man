# Survey Man

Premium surveying and geospatial website for [Survey Man](https://surveyman.in/).

## Stack

- React + Vite
- Tailwind CSS
- GSAP + ScrollTrigger
- Lenis
- Three.js
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Company facts are taken from the live Survey Man site. Projects and testimonials are marked as placeholders until real case studies and quotes are supplied.
